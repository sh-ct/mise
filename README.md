# mise

A recipe app for capturing recipes from anywhere, organising them, and cooking from them one step at a time — on phone or desktop.

Status: Phase 0 (foundations). See [docs/PLAN.md](docs/PLAN.md) and [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

```bash
pnpm install
pnpm nx serve web
```
